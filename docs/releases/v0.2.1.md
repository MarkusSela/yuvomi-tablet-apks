# Yuvomi Tablet — v0.2.1

## Added features

- ⚙️ Native Android settings screen separate from the WebView and the Yuvomi calendar.
- 💡 Manual and automatic brightness with the actual system state displayed.
- 🔊 Android volume controls for media, alarms/reminders, notifications, ringtone and system sounds.
- 🔔 Touch sounds toggle.
- 🔄 Global orientation: automatic, portrait or landscape.
- ⏱️ Configurable display-off timeout.
- 🖥️ Android screensaver status and link to its system settings.
- 🔐 Guided request for the Android `WRITE_SETTINGS` permission when required.

## Variants

The personal and generic variants contain the same native controls. The generic variant still asks for the Yuvomi endpoint on first launch.

## Status

- v0.2.1 source updated in both variants.
- Previous debug APKs removed from the public repository.
- The generic release is rebuilt through the generic-only GitHub Actions verification workflow.
- The fixed portrait lock is removed so global Android orientation can be applied when permission is granted.
- Native settings do not modify the Yuvomi calendar WebView.

## Generic correction

- 🧭 Removed the launcher activity portrait lock from the generic manifest.
- 📦 Rebuilds the native `TabletSettingsActivity` in a release APK.
- ✅ Keeps tablet controls outside the Yuvomi calendar WebView.
